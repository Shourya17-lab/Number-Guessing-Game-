# Number Guessing Game

A simple number guessing game written in C.

## Features
- Random number generation
- User input
- Hint if the guess is too high or too low
- Counts the number of attempts

## How to Run

Compile:

```bash
gcc main.c -o game
```

Run:

```bash
./game
```

## Technologies Used
- C
- GCC
- VS Code
